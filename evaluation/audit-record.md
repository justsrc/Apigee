# Repository audit record

This file records the Git history and the defects found while auditing the project. It
is the audit trail the commit messages point at; the commits are the authoritative
record of what changed.

## Baseline

The repository had no commits when this audit started. Everything that existed at that
point was committed together as the initial baseline, before any fix. Reviewers can
inspect the pre-fix state with `git show <baseline>`.

Excluded from the baseline:

- `research/__pycache__/*.pyc` and `tests/__pycache__/*.pyc`. Python bytecode caches are
  generated by running the scripts and are not source. They are now ignored by
  `.gitignore` and regenerated on demand. Nothing else was excluded.

Not treated as secrets: the `AIza...` strings in `research/pages/*.txt` are the public
Google devsite web-client keys that appear in every fetched `cloud.google.com` page. The
`edgecli:edgeclisecret` pair in `research/notes-rw-opdk.md` is a documented public
credential quoted from an open-source issue. Neither grants access to anything.
