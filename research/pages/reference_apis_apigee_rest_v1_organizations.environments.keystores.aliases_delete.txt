<div id="google.cloud.apigee.v1.KeystoreService.DeleteAlias" class="section">

</div>

<div id="description" class="section">

Deletes an alias.

</div>

<div id="body" class="section">

<div id="body.HTTP_TEMPLATE" class="section">

### HTTP request

`DELETE https://apigee.googleapis.com/v1/{name=organizations/*/environments/*/keystores/*/aliases/*}`

The URL uses [gRPC Transcoding](https://google.aip.dev/127) syntax.

</div>

<div id="body.PATH_PARAMETERS" class="section">

### Path parameters

| Parameters |  |
| --- | --- |
| name | string Required. Name of the alias. Use the following format in your request: organizations/{org}/environments/{env}/keystores/{keystore}/aliases/{alias} . Authorization requires the following IAM permission on the specified resource name : apigee.keystorealiases.delete |

</div>

<div id="body.request_body" class="section">

### Request body

The request body must be empty.

</div>

<div id="body.response_body" class="section">

### Response body

If successful, the response body contains an instance of [`Alias`](/apigee/docs/reference/apis/apigee/rest/v1/Alias).

</div>

<div id="body.aspect" class="section">

### Authorization scopes

Requires the following OAuth scope:

- `https://www.googleapis.com/auth/cloud-platform`

</div>
