This topic explains how to enable one-way TLS and mTLS on the ingressgateway.

## Configuring one-way TLS

Use one-way TLS to secure API proxy endpoints on the ingress gateway. To enable one-way TLS, you configure the ingress with TLS cert/key pairs or with a Kubernetes Secret, as explained in the following options.

### Option 1: key/cert pair

Provide SSL cert and key files in the `virtualhosts` property in your overrides file:

<div>

</div>

``` devsite-click-to-copy
virtualhosts:
  - name: $ENVIRONMENT_GROUP_NAME
    sslCertPath: "$CERT_FILE"
    sslKeyPath: "$KEY_FILE"
```

**Note:** See

[`virtualhosts.name`](/apigee/docs/hybrid/v1.17/config-prop-ref#virtualhosts-name)

[`virtualhosts.sslCertPath`](/apigee/docs/hybrid/v1.17/config-prop-ref#virtualhosts-sslcertpath)

[`virtualhosts.sslKeyPath`](/apigee/docs/hybrid/v1.17/config-prop-ref#virtualhosts-sslkeypath)

Where `$ENVIRONMENT_GROUP_NAME` is the name of an environment group with corresponding host aliases, and `$CERT_FILE` and `$KEY_FILE` are TLS key and certificate files. See [Create TLS certificates](/apigee/docs/hybrid/v1.17/install-create-tls-certificates).

**Tip:** For security purposes, it is best practice to have a separate TLS cert/key pair for each virtual host. If you are using a Subject Alternative Name (SAN ) certificate, this TLS cert/key pair should be used on one virtual host that is shared across the domain.

### Option 2: Kubernetes Secret

Create a <a href="https://kubernetes.io/docs/concepts/configuration/secret/" class="external">Kubernetes Secret</a> and add it to your overrides file.

Create the Secret in the **`apigee`** namespace:

<div>

</div>

``` devsite-terminal

kubectl create -n APIGEE_NAMESPACE secret generic $SECRET_NAME  \
  --from-file=key=$KEY_FILE \
  --from-file=cert=$CERT_FILE
```

Configure the `virtualhosts` property in your overrides file:

<div>

</div>

``` devsite-click-to-copy
virtualhosts:
  - name: $ENVIRONMENT_GROUP_NAME
    tlsMode: SIMPLE  # Note: SIMPLE is the default, so it is optional.
    sslSecret: $SECRET_NAME
```

**Note:** See

- [`virtualhosts.name`](/apigee/docs/hybrid/v1.17/config-prop-ref#virtualhosts-name)
- [`virtualhosts.tlsMode`](/apigee/docs/hybrid/v1.17/config-prop-ref#virtualhosts-tlsmode)
- [`virtualhosts.sslSecret`](/apigee/docs/hybrid/v1.17/config-prop-ref#virtualhosts-sslsecret)

## Configuring mTLS

Instead of one-way TLS, you can configure <a href="https://en.wikipedia.org/wiki/Mutual_authentication" class="external">mTLS</a> on the ingress gateway. There are two options for configuring mTLS, as explained below.

### Option 1: key/cert pair and CA file

Provide TLS certificate data containing Certificate Authority certificates:

<div>

</div>

``` devsite-click-to-copy
virtualhosts:
  - name: $ENVIRONMENT_GROUP_NAME
    tlsMode: MUTUAL
    caCertPath: "$CA_FILE"
    sslCertPath: "$CERT_FILE"
    sslKeyPath: "$KEY_FILE"
```

**Note:** See

- [`virtualhosts.name`](/apigee/docs/hybrid/v1.17/config-prop-ref#virtualhosts-name)
- [`virtualhosts.tlsMode`](/apigee/docs/hybrid/v1.17/config-prop-ref#virtualhosts-tlsmode)
- [`virtualhosts.caCertPath`](/apigee/docs/hybrid/v1.17/config-prop-ref#virtualhosts-cacertpath)
- [`virtualhosts.sslCertPath`](/apigee/docs/hybrid/v1.17/config-prop-ref#virtualhosts-sslcertpath)
- [`virtualhosts.sslKeyPath`](/apigee/docs/hybrid/v1.17/config-prop-ref#virtualhosts-sslkeypath)

Where `$ENVIRONMENT_GROUP_NAME` is the name of an environment group with corresponding host aliases, `$CA_FILE` specifies TLS certificate data (CA bundle file) containing Certificate Authority certificates, and `$CERT_FILE` and `$KEY_FILE` are TLS key and certificate files. See [Create TLS certificates](/apigee/docs/hybrid/v1.17/install-create-tls-certificates).

### Option 2: Kubernetes Secrets

Create two Kubernetes Secrets. The first secret is for the SSL cert/key pair and the second is for the CA. Then, add them to your overrides file.

Create two Kubernetes secrets the **`apigee`** namespace:

<div>

</div>

``` devsite-terminal

kubectl create -n APIGEE_NAMESPACE secret generic $SECRET_NAME  \
  --from-file=key=$KEY_FILE \
  --from-file=cert=$CERT_FILE
```

Create a secret for the CA:

<div>

</div>

``` devsite-terminal
kubectl create -n APIGEE_NAMESPACE secret generic $SECRET_NAME-cacert  \
  --from-file=cacert=$CA_FILE
```

Configure the `virtualhosts` property in your overrides file:

<div>

</div>

``` devsite-click-to-copy
virtualhosts:
  - name: $ENVIRONMENT_GROUP_NAME
    tlsMode: MUTUAL  # Note: Be sure to specify MUTUAL
    sslSecret: $SECRET_NAME
```

**Note:** See

- [`virtualhosts.name`](/apigee/docs/hybrid/v1.17/config-prop-ref#virtualhosts-name)
- [`virtualhosts.tlsMode`](/apigee/docs/hybrid/v1.17/config-prop-ref#virtualhosts-tlsmode)
- [`virtualhosts.sslSecret`](/apigee/docs/hybrid/v1.17/config-prop-ref#virtualhosts-sslsecret)
