<div id="google.cloud.apigee.v1.KeystoreService.UpdateAlias" class="section">

</div>

<div id="description" class="section">

Updates the certificate in an alias.

The updated certificate must be in PEM- or DER-encoded X.509 format.

</div>

<div id="body" class="section">

<div id="body.HTTP_TEMPLATE" class="section">

### HTTP request

`PUT https://apigee.googleapis.com/v1/{name=organizations/*/environments/*/keystores/*/aliases/*}`

The URL uses [gRPC Transcoding](https://google.aip.dev/127) syntax.

</div>

<div id="body.PATH_PARAMETERS" class="section">

### Path parameters

| Parameters |  |
| --- | --- |
| name | string Required. Name of the alias. Use the following format in your request: organizations/{org}/environments/{env}/keystores/{keystore}/aliases/{alias} Authorization requires the following IAM permission on the specified resource name : apigee.keystorealiases.update |

</div>

<div id="body.QUERY_PARAMETERS" class="section">

### Query parameters

| Parameters |  |
| --- | --- |
| ignoreExpiryValidation | boolean Required. Flag that specifies whether to ignore expiry validation. If set to true , no expiry validation will be performed. |
| ignoreNewlineValidation | boolean Flag that specifies whether to ignore newline validation. If set to true , no error is thrown when the file contains a certificate chain with no newline between each certificate. Defaults to false . |

</div>

<div id="body.request_body" class="section">

### Request body

The request body contains an instance of [`HttpBody`](/apigee/docs/reference/apis/apigee/rest/v1/organizations.environments.keystores.aliases#HttpBody).

</div>

<div id="body.response_body" class="section">

### Response body

If successful, the response body contains an instance of [`Alias`](/apigee/docs/reference/apis/apigee/rest/v1/Alias).

</div>

<div id="body.aspect" class="section">

### Authorization scopes

Requires the following OAuth scope:

- `https://www.googleapis.com/auth/cloud-platform`

</div>
