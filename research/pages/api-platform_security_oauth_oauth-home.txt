### <span id="reference"></span>OAuth 2.0 policies

These policies allow you to perform OAuth 2.0 operations in an Apigee API proxy:

- [OAuthV2 policy](/apigee/docs/api-platform/reference/policies/oauthv2-policy): The heart of the Apigee OAuth 2.0 implementation. It lets you configure OAuth 2.0 *operations* on Apigee that generate access and refresh tokens, issue authorization codes, and validate tokens. This topic includes code samples to help illustrate how things work.
- [GetOAuthV2Info policy](/apigee/docs/api-platform/reference/policies/get-oauth-v2-info-policy): Gets attributes of tokens and makes them available to policies and code executing in an API proxy. This policy type can be useful when you need to configure dynamic, conditional behavior based on a value in an access token. See also [Customizing access tokens](/apigee/docs/api-platform/security/oauth/customizing-access-tokens).
- [SetOAuthV2Info policy](/apigee/docs/api-platform/reference/policies/set-oauth-v2-info-policy): Updates the profile of an access token. For example, you may want to embed a tag that is unique to your business. See also [Customizing access tokens](/apigee/docs/api-platform/security/oauth/customizing-access-tokens).
