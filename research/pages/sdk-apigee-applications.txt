<div id="NAME" class="section">

NAME

<span class="normalfont"> gcloud apigee applications - manage third-party applications which call Apigee API proxies </span>

</div>

<div id="SYNOPSIS" class="section">

SYNOPSIS

<span class="normalfont"> `gcloud apigee applications` [`COMMAND`](#COMMAND) \[[`GCLOUD_WIDE_FLAG`](#GCLOUD-WIDE-FLAGS)` …`\] </span>

</div>

<div id="DESCRIPTION" class="section">

DESCRIPTION

Manage third-party applications which call Apigee API proxies.

`gcloud apigee applications` manages applications that want to use APIs exposed via Apigee.

</div>

<div id="EXAMPLES" class="section">

EXAMPLES

To get the names and UUIDs of all applications in the active Cloud Platform project, run:

<div>

</div>

``` devsite-click-to-copy
gcloud apigee applications list
```

To get a JSON representation of an application in the active Cloud Platform project, including its API keys, run:

<div>

</div>

``` devsite-click-to-copy
gcloud apigee applications describe APP_UUID --format=json
```

</div>

<div id="GCLOUD-WIDE-FLAGS" class="section">

GCLOUD WIDE FLAGS

These flags are available to all commands: [`--help`](/sdk/gcloud/reference#--help).

Run `$ `[`gcloud help`](/sdk/gcloud/reference) for details.

</div>

<div id="COMMAND" class="section">

COMMANDS

`COMMAND` is one of the following:

<span class="normalfont">[`describe`](/sdk/gcloud/reference/apigee/applications/describe)</span>  
Describe an Apigee application.

<span class="normalfont">[`list`](/sdk/gcloud/reference/apigee/applications/list)</span>  
List Apigee applications.

</div>
