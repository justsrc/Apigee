Before you can install Apigee hybrid, you must meet the following prerequisites:

Done?

Prerequisite

Description

**Google Cloud billing account**

You must have a Google Cloud account with active billing. For more information, see [Create a new billing account](/billing/docs/how-to/manage-billing-account#create_a_new_billing_account).

**Google Cloud project**

Create a new Google Cloud project for the Apigee hybrid installation. For more information, see [Creating a project](/resource-manager/docs/creating-managing-projects#creating_a_project).

If you'd prefer to use Cloud Identity to manage your organizational identity with Apigee, see <a href="https://support.google.com/cloudidentity#topic=7516500" class="external">Cloud Identity Help</a>. Although not needed for Apigee hybrid, Cloud Identity might be useful if you plan to use other Google Cloud services or have multiple members of your organization access the product.

**Clock synchronization**

Apigee hybrid uses the Cassandra database, and Cassandra relies on Network Time Protocol (NTP) synchronization to maintain data consistency. Before you begin your hybrid installation, we recommend you use Network Time Protocol (NTP) to synchronize the clocks on all nodes and application servers. If you plan to install hybrid into multiple regions, be sure they are synchronized with NTP across all regions.

**Software**

Install the following software on your administrative machine:

- <a href="/sdk/docs/install" class="external">gcloud CLI</a> (required for command line provisioning steps).
  - After the gcloud CLI is installed, run `gcloud components update` to get the latest gcloud components.
- <a href="https://curl.haxx.se/" class="external"><code translate="no" dir="ltr">curl</code></a> (recommended)
- If you are installing Apigee hybrid on EKS and you are using Kubernetes 1.24 or newer, install the <a href="https://github.com/kubernetes-sigs/aws-ebs-csi-driver" class="external">Kubernetes CSI driver for Amazon EBS</a>.

**Hardware**

Review the following information before installing hybrid:

- [Minimum cluster configurations](/apigee/docs/hybrid/v1.17/cluster-overview)
- [Configuring dedicated node pools](/apigee/docs/hybrid/v1.17/configure-dedicated-nodes)
- [Configure Cassandra for production](/apigee/docs/hybrid/v1.17/cassandra-production)
- [Configuring authentication for Cassandra](/apigee/docs/hybrid/v1.17/cassandra-tls)
- [StorageClass configuration](/apigee/docs/hybrid/v1.17/cassandra-config)
- [Secure ports usage](/apigee/docs/hybrid/v1.17/ports)

**Note:** If you plan to enable Google Cloud [Virtual Private Cloud (VPC) Service Controls](https://cloud.google.com/vpc-service-controls) with your Apigee hybrid installation, see [Using VPC Service Controls with Apigee and Apigee hybrid](/apigee/docs/api-platform/security/vpc-sc) for instructions before you proceed.
