## Helm supported version

Apigee hybrid supports Helm v3.14.2+.

## Helm charts for Apigee hybrid components

The hybrid components are installed and managed by the following Helm charts. The table is arranged in the order you will typically install them in during a fresh installation.

| Scope | Components | Helm chart |
| --- | --- | --- |
| Apigee operator | Apigee operator | apigee-operator |
| Storage | Cassandra | apigee-datastore |
| In‑memory storage | Redis | apigee-redis |
| Reporting | Logger Metrics | apigee-telemetry |
| Ingress | Apigee Ingress gateway | apigee-ingress-manager |
| Organization | Apigee Connect Agent MART UDCA Watcher | apigee-org |
| Environment | Runtime Synchronizer | apigee-env |
| Environment group | virtualhost | apigee-virtualhost |

**Note:** The hybrid Helm charts depend on the Apigee hybrid Custom Resource Definitions (CRDs) being installed. See [Install the Apigee hybrid CRDs](/apigee/docs/hybrid/v1.17/install-crds) in the Installation guide.

## Recommended upgrade order

We recommend that you upgrade the Helm charts in the following order:

1.  `apigee-operator`
2.  `apigee-datastore`
3.  `apigee-telemetry`
4.  `apigee-redis`
5.  `apigee-ingress-manager`
6.  `apigee-org`
7.  `apigee-env`
8.  `apigee-virtualhost`

## Service accounts and Helm charts

The following table lists the Google Cloud service accounts used by the Apigee Helm charts:

| Apigee Helm chart | Service account | IAM roles |
| --- | --- | --- |
| apigee-operator | apigee-guardrails | Service Usage Viewer |
| apigee-datastore | apigee-cassandra | Storage Object Admin |
| apigee-telemetry | apigee-logger apigee-metrics | Logs Writer Monitoring Metric Writer |
| apigee-org | apigee-mart apigee-watcher apigee-mint-task-scheduler (optional) | Apigee Connect Agent Apigee Runtime Agent No role required |
| apigee-env | apigee-runtime apigee-synchronizer | No role required Apigee Synchronizer Manager , Storage Object Admin |

See: [About service accounts](/apigee/docs/hybrid/v1.17/sa-about)
