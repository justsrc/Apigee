## Supported platforms

You can install Apigee hybrid on a number of platforms, including Google Distributed Cloud (on bare metal or VMware), AWS, Bare Metal, EKS, Google Kubernetes Engine (GKE), OpenShift, and others. For a list of supported platforms see [Apigee hybrid: supported platforms](/apigee/docs/hybrid/supported-platforms).

## Permissions

Each supported platform has its own permission requirements for creating a cluster. As cluster owner, you can proceed to install the Apigee-specific components (including cert-manager and the Apigee runtime) into the cluster. However, if you want to delegate to another user the installation of the runtime components into the cluster, you can manage the necessary permissions through Kubernetes <a href="https://kubernetes.io/docs/reference/access-authn-authz/rbac/" class="external">authn-authz</a>.

For a complete list of Kubernetes resources and custom resources that are used by Apigee installations, see [Kubernetes and custom resources used by Apigee](https://docs.cloud.google.com/apigee/docs/hybrid/kubernetes-resources).

## Prerequisites

This section describes tasks you must accomplish before you begin the runtime plane quickstart install.

Complete the tasks in [Part 1: Project and org setup](/apigee/docs/hybrid/v1.17/precog-overview) before you begin the runtime installation:

<div>

Meet the [Prerequisites](/apigee/docs/hybrid/v1.17/prerequisites) having a Google Cloud project, a billing account, and the `gcloud` CLI installed.

</div>

<div>

Enable the APIs for Google Cloud services in [Step 1: Enable APIs](/apigee/docs/hybrid/v1.17/precog-enableapi).

</div>

<div>

Create an Apigee organization in [Step 2: Create an organization](/apigee/docs/hybrid/v1.17/precog-provision).

</div>

<div>

Create an Apigee environment and environment group in [Step 3: Create an environment group](/apigee/docs/hybrid/v1.17/precog-add-environment).

</div>

**Note about VPC Service Controls:** If you plan to enable Google Cloud [Virtual Private Cloud (VPC) Service Controls](https://cloud.google.com/vpc-service-controls) with your Apigee hybrid installation, see [Using VPC Service Controls with Apigee and Apigee hybrid](/apigee/docs/api-platform/security/vpc-sc) for instructions before you proceed.
