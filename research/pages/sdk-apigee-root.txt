<div id="NAME" class="section">

NAME

<span class="normalfont"> gcloud apigee - manage Apigee resources </span>

</div>

<div id="SYNOPSIS" class="section">

SYNOPSIS

<span class="normalfont"> `gcloud apigee` [`GROUP`](#GROUP) \[[`GCLOUD_WIDE_FLAG`](#GCLOUD-WIDE-FLAGS)` …`\] </span>

</div>

<div id="DESCRIPTION" class="section">

DESCRIPTION

Manage Apigee resources.

</div>

<div id="EXAMPLES" class="section">

EXAMPLES

To list API proxies in the active Cloud Platform project, run:

<div>

</div>

``` devsite-click-to-copy
gcloud apigee apis list
```

To deploy an API proxy named `hello-world` to the `test` environment, run:

<div>

</div>

``` devsite-click-to-copy
gcloud apigee apis deploy --environment=test --api=hello-world
```

To get the status of that deployment, run:

<div>

</div>

``` devsite-click-to-copy
gcloud apigee deployments describe --environment=test --api=hello-world
```

To undeploy that API proxy, run:

<div>

</div>

``` devsite-click-to-copy
gcloud apigee apis undeploy --environment=test --api=hello-world
```

</div>

<div id="GCLOUD-WIDE-FLAGS" class="section">

GCLOUD WIDE FLAGS

These flags are available to all commands: [`--help`](/sdk/gcloud/reference#--help).

Run `$ `[`gcloud help`](/sdk/gcloud/reference) for details.

</div>

<div id="GROUP" class="section">

GROUPS

`GROUP` is one of the following:

<span class="normalfont">[`apis`](/sdk/gcloud/reference/apigee/apis)</span>  
Manage Apigee API proxies.

<span class="normalfont">[`applications`](/sdk/gcloud/reference/apigee/applications)</span>  
Manage third-party applications which call Apigee API proxies.

<span class="normalfont">[`deployments`](/sdk/gcloud/reference/apigee/deployments)</span>  
Manage deployments of Apigee API proxies in runtime environments.

<span class="normalfont">[`developers`](/sdk/gcloud/reference/apigee/developers)</span>  
Manage Apigee developers.

<span class="normalfont">[`environments`](/sdk/gcloud/reference/apigee/environments)</span>  
Manage Apigee environments.

<span class="normalfont">[`organizations`](/sdk/gcloud/reference/apigee/organizations)</span>  
Manage Apigee organizations.

<span class="normalfont">[`products`](/sdk/gcloud/reference/apigee/products)</span>  
Manage Apigee API products.

</div>
