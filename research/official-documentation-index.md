# Official documentation index

Generated by `python3 research/build_doc_index.py`. Every row is a page that was
actually fetched into `research/pages/`, not a link taken from a search result.

**Coverage statement.** This index contains 284 Apigee documentation pages
that were fetched and read during this project. That is not every page Google has
published. The set was built by walking the navigation tree of seed pages, so it
reflects what a reader starting from those seeds would reach. Areas that are thin
are thin because the seeds led there, and the count below should be read that way.

**Verification.** status not re-verified in this run (each page returned 200 when fetched).

## How to re-verify

```bash
cd research
./fetch.sh <doc-path>              # fetch one page, prints status
python3 build_doc_index.py --verify # re-check every URL in this index
python3 build_doc_index.py --check-known  # re-check the recorded 404 list
```

## Records

URLs that returned 404 during research are listed in `notes-known-404.txt`.
Negative results matter: a URL that 404s today may be a page that moved, and
citing it anyway is how a skill ends up teaching a dead link.
