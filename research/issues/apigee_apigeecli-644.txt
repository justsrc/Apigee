--- BODY ---
If the `apigeecli sharedflows deploy` command fails, we still get an exit status of 0. This means we are unable to fail our builds if sharedflow deployments fail.

The equivalent command for `apigeecli apis deploy` _does_ fail with a non-zero exit code, which means the process of deploying sharedflows and apiproxies does not appear to work consistently.

```
➜ code git:(task/test) >>> apigeecli sharedflows deploy --org my-org --account  ~/.gcloud/my-key.json --env my-env --name sharedflow-x-powered-by --rev 12 --ovr --wait
{
        "environment": "my-env",
        "apiProxy": "sharedflow-x-powered-by",
        "revision": "12",
        "deployStartTime": "1740661465612"
}

Checking deployment status in 10 seconds
Sharedflow deployment failed with status:  ERROR
➜ code git:(task/test) >>> echo $? 
0
```
