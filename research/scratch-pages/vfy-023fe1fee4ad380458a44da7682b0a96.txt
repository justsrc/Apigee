<div id="NAME" class="section">

NAME

<span class="normalfont"> gcloud alpha apigee apis - manage Apigee API proxies </span>

</div>

<div id="SYNOPSIS" class="section">

SYNOPSIS

<span class="normalfont"> `gcloud alpha apigee apis` [`COMMAND`](#COMMAND) \[[`GCLOUD_WIDE_FLAG`](#GCLOUD-WIDE-FLAGS)` …`\] </span>

</div>

<div id="DESCRIPTION" class="section">

DESCRIPTION

`(ALPHA)` Manage Apigee API proxies.

</div>

<div id="EXAMPLES" class="section">

EXAMPLES

To list all the API proxies in the active Cloud Platform project, run:

<div>

</div>

``` devsite-click-to-copy
gcloud alpha apigee apis list
```

To get details about a specific API proxy in a specific Apigee organization, run:

<div>

</div>

``` devsite-click-to-copy
gcloud alpha apigee apis describe PROXY_NAME --organization=ORG_NAME
```

To get a JSON object containing revision-level details about an API proxy, run:

<div>

</div>

``` devsite-click-to-copy
gcloud alpha apigee apis describe PROXY_NAME --verbose --format=json
```

To deploy the most recent revision of an API proxy into the `eval` deployment environment, run:

<div>

</div>

``` devsite-click-to-copy
gcloud alpha apigee apis deploy --api=PROXY_NAME --environment=eval
```

To deploy the first revision of that API proxy into the `release` deployment environment, run:

<div>

</div>

``` devsite-click-to-copy
gcloud alpha apigee apis deploy 1 --api=PROXY_NAME --environment=release
```

To undeploy whatever revision of PROXY_NAME is currently deployed in ENVIRONMENT, run:

<div>

</div>

``` devsite-click-to-copy
gcloud alpha apigee apis undeploy --api=PROXY_NAME --environment=ENVIRONMENT
```

</div>

<div id="GCLOUD-WIDE-FLAGS" class="section">

GCLOUD WIDE FLAGS

These flags are available to all commands: [`--help`](/sdk/gcloud/reference#--help).

Run `$ `[`gcloud help`](/sdk/gcloud/reference) for details.

</div>

<div id="COMMAND" class="section">

COMMANDS

`COMMAND` is one of the following:

<span class="normalfont">[`delete`](/sdk/gcloud/reference/alpha/apigee/apis/delete)</span>  
`(ALPHA)` Delete an Apigee API proxy.

<span class="normalfont">[`deploy`](/sdk/gcloud/reference/alpha/apigee/apis/deploy)</span>  
`(ALPHA)` Deploy an Apigee API proxy to an environment.

<span class="normalfont">[`describe`](/sdk/gcloud/reference/alpha/apigee/apis/describe)</span>  
`(ALPHA)` Describe an Apigee API proxy.

<span class="normalfont">[`import`](/sdk/gcloud/reference/alpha/apigee/apis/import)</span>  
`(ALPHA)` Import an Apigee API proxy from local files.

<span class="normalfont">[`list`](/sdk/gcloud/reference/alpha/apigee/apis/list)</span>  
`(ALPHA)` List Apigee API proxies.

<span class="normalfont">[`undeploy`](/sdk/gcloud/reference/alpha/apigee/apis/undeploy)</span>  
`(ALPHA)` Undeploy an Apigee API proxy from an environment.

</div>

<div id="NOTES" class="section">

NOTES

<div>

</div>

``` devsite-click-to-copy
gcloud apigee apis
```

<div>

</div>

``` devsite-click-to-copy
gcloud beta apigee apis
```
