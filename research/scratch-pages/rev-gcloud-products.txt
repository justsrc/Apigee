<div id="NAME" class="section">

NAME

<span class="normalfont"> gcloud apigee products - manage Apigee API products </span>

</div>

<div id="SYNOPSIS" class="section">

SYNOPSIS

<span class="normalfont"> `gcloud apigee products` [`COMMAND`](#COMMAND) \[[`GCLOUD_WIDE_FLAG`](#GCLOUD-WIDE-FLAGS)` …`\] </span>

</div>

<div id="DESCRIPTION" class="section">

DESCRIPTION

Manage Apigee API products.

`gcloud apigee products` manipulates API products. These are collections of deployed API resources, combined with quota settings and metadata, used to deliver customized and productized API bundles to the developer community.

</div>

<div id="EXAMPLES" class="section">

EXAMPLES

To list all API products in the active Cloud Platform project, run:

<div>

</div>

``` devsite-click-to-copy
gcloud apigee products list
```

To create an API product named `my-apis` by answering interactive prompts about its included proxies and access policies, run:

<div>

</div>

``` devsite-click-to-copy
gcloud apigee products create my-apis
```

To create an API product named `prod-apis` that makes every API proxy deployed to the `prod` environment publicly available, run:

<div>

</div>

``` devsite-click-to-copy
gcloud apigee products create prod-apis --environments=prod --all-proxies --public-access
```

To get a JSON object describing an existing API product, run:

<div>

</div>

``` devsite-click-to-copy
gcloud apigee products describe PRODUCT_NAME --organization=ORG_NAME --format=json
```

To add another API proxy to an existing API product, run:

<div>

</div>

``` devsite-click-to-copy
gcloud apigee products update PRODUCT_NAME --add-api=API_NAME
```

To edit the publicly visible name and description of an API product, run:

<div>

</div>

``` devsite-click-to-copy
gcloud apigee products update PRODUCT_NAME --display-name="New Name" --description="A new description of this product."
```

To make an existing product publicly visible and automatically allow developers access to it, run:

<div>

</div>

``` devsite-click-to-copy
gcloud apigee products update PRODUCT_NAME --public-access --automatic-approval
```

To delete an existing API product, run:

<div>

</div>

``` devsite-click-to-copy
gcloud apigee products delete PRODUCT_NAME
```

</div>

<div id="COMMAND" class="section">

COMMANDS

`COMMAND` is one of the following:

<span class="normalfont">[`create`](/sdk/gcloud/reference/apigee/products/create)</span>  
Create an Apigee API product.

<span class="normalfont">[`delete`](/sdk/gcloud/reference/apigee/products/delete)</span>  
Delete an Apigee API product.

<span class="normalfont">[`describe`](/sdk/gcloud/reference/apigee/products/describe)</span>  
Describe an Apigee API product.

<span class="normalfont">[`list`](/sdk/gcloud/reference/apigee/products/list)</span>  
List Apigee API products.

<span class="normalfont">[`update`](/sdk/gcloud/reference/apigee/products/update)</span>  
Update an existing Apigee API product.

</div>
