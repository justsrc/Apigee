<div id="description" class="section">

Lists all revisions for an API proxy.

</div>

<div id="body" class="section">

<div id="body.HTTP_TEMPLATE" class="section">

### HTTP request

`GET https://apigee.googleapis.com/v1/{parent=organizations/*/apis/*}/revisions`

The URL uses [gRPC Transcoding](https://google.aip.dev/127) syntax.

</div>

<div id="body.PATH_PARAMETERS" class="section">

### Path parameters

| Parameters |  |
| --- | --- |
| parent | string Required. Name of the API proxy in the following format: organizations/{org}/apis/{api} If the API Proxy resource has the space attribute set, IAM permissions are checked against the Space resource path. To learn more, read the Apigee Spaces Overview . Authorization requires the following IAM permission on the specified resource parent : apigee.proxyrevisions.list |

</div>

<div id="body.request_body" class="section">

### Request body

The request body must be empty.

</div>

<div id="body.response_body" class="section">

### Response body

If successful, the response body contains an instance of [`ListValue`](https://protobuf.dev/reference/protobuf/google.protobuf/#list-value).

</div>

<div id="body.aspect" class="section">

### Authorization scopes

Requires the following OAuth scope:

- `https://www.googleapis.com/auth/cloud-platform`

</div>
