<div id="NAME" class="section">

NAME

<span class="normalfont"> gcloud beta apigee archives - manage Apigee archive deployments </span>

</div>

<div id="SYNOPSIS" class="section">

SYNOPSIS

<span class="normalfont"> `gcloud beta apigee archives` [`COMMAND`](#COMMAND) \[[`GCLOUD_WIDE_FLAG`](#GCLOUD-WIDE-FLAGS)` …`\] </span>

</div>

<div id="DESCRIPTION" class="section">

DESCRIPTION

`(BETA)` Manage Apigee archive deployments.

</div>

<div id="EXAMPLES" class="section">

EXAMPLES

To deploy a local archive deployment remotely to the management plane in the `test` environment, run:

<div>

</div>

``` devsite-click-to-copy
gcloud beta apigee archives deploy --environment=test
```

To list all archive deployments in the `dev` environment, run:

<div>

</div>

``` devsite-click-to-copy
gcloud beta apigee archives list --environment=dev
```

To describe the archive deployment with id `abcdef01234` in the `demo` environment of the `my-org` Apigee organization, run:

<div>

</div>

``` devsite-click-to-copy
gcloud beta apigee archives describe abcdef01234 --environment=demo --organization=my-org
```

To update the labels of the archive deployment with id `uvxwzy56789` in the `test` environment, run:

<div>

</div>

``` devsite-click-to-copy
gcloud beta apigee archives update uvxwzy56789 --environment=demo --update-labels=foo=1,bar=2
```

</div>

<div id="GCLOUD-WIDE-FLAGS" class="section">

GCLOUD WIDE FLAGS

These flags are available to all commands: [`--help`](/sdk/gcloud/reference#--help).

Run `$ `[`gcloud help`](/sdk/gcloud/reference) for details.

</div>

<div id="COMMAND" class="section">

COMMANDS

`COMMAND` is one of the following:

<span class="normalfont">[`delete`](/sdk/gcloud/reference/beta/apigee/archives/delete)</span>  
`(BETA)` Delete an Apigee archive deployment.

<span class="normalfont">[`deploy`](/sdk/gcloud/reference/beta/apigee/archives/deploy)</span>  
`(BETA)` Deploy an Apigee archive deployment to an environment.

<span class="normalfont">[`describe`](/sdk/gcloud/reference/beta/apigee/archives/describe)</span>  
`(BETA)` Describe an Apigee archive deployment.

<span class="normalfont">[`list`](/sdk/gcloud/reference/beta/apigee/archives/list)</span>  
`(BETA)` List Apigee archive deployments.

<span class="normalfont">[`update`](/sdk/gcloud/reference/beta/apigee/archives/update)</span>  
`(BETA)` Update an existing Apigee archive deployment.

</div>

NOTES

</div>

