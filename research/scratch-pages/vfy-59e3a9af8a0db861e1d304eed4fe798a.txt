<div id="description" class="section">

Gets the deployment of an API proxy revision and actual state reported by runtime pods.

</div>

<div id="body" class="section">

<div id="body.HTTP_TEMPLATE" class="section">

### HTTP request

`GET https://apigee.googleapis.com/v1/{name=organizations/*/environments/*/apis/*/revisions/*}/deployments`

The URL uses [gRPC Transcoding](https://google.aip.dev/127) syntax.

</div>

<div id="body.PATH_PARAMETERS" class="section">

### Path parameters

| Parameters |  |
| --- | --- |
| name | string Required. Name representing an API proxy revision in an environment in the following format: organizations/{org}/environments/{env}/apis/{api}/revisions/{rev} If the API proxy resource has the space attribute set, IAM permissions are checked differently . To learn more, read the Apigee Spaces Overview . Authorization requires the following IAM permission on the specified resource name : apigee.deployments.get |

</div>

<div id="body.request_body" class="section">

### Request body

The request body must be empty.

</div>

<div id="body.response_body" class="section">

### Response body

If successful, the response body contains an instance of [`Deployment`](/apigee/docs/reference/apis/apigee/rest/v1/organizations.environments.deployments#Deployment).

</div>

<div id="body.aspect" class="section">

### Authorization scopes

Requires the following OAuth scope:

- `https://www.googleapis.com/auth/cloud-platform`

</div>
