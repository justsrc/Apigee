<div id="NAME" class="section">

NAME

<span class="normalfont"> gcloud apigee organizations list - list Apigee organizations and their paired Cloud Platform projects </span>

</div>

<div id="SYNOPSIS" class="section">

SYNOPSIS

<span class="normalfont"> `gcloud apigee organizations list` \[<span class="flag">[`--filter`](#--filter)=`EXPRESSION`\]</span> \[<span class="flag">[`--limit`](#--limit)=`LIMIT`\]</span> \[<span class="flag">[`--page-size`](#--page-size)=`PAGE_SIZE`\]</span> \[<span class="flag">[`--sort-by`](#--sort-by)=\[`FIELD`,</span><span class="flag">…\]\]</span> \[<span class="flag">[`--uri`](#--uri)\]</span> \[[`GCLOUD_WIDE_FLAG`](#GCLOUD-WIDE-FLAGS)` …`\] </span>

</div>

<div id="DESCRIPTION" class="section">

DESCRIPTION

List Apigee organizations and their paired Cloud Platform projects.

`gcloud apigee organizations list` lists all organizations to which the user's [`gcloud auth`](/sdk/gcloud/reference/auth) credentials have access, even if they don't match the active Cloud Platform project.

Apigee organizations are distinct from Cloud Platform organizations, and usually have a one-to-one relationship with Cloud Platform projects.

</div>

<div id="EXAMPLES" class="section">

EXAMPLES

To list all accessible organizations and their associated Cloud Platform projects, run:

<div>

</div>

``` devsite-click-to-copy
gcloud apigee organizations list
```

To get a JSON array of all organizations whose Cloud Platform project names contain the word `sandbox`, run:

<div>

</div>

``` devsite-click-to-copy
gcloud apigee organizations list --format=json --filter="project:(sandbox)"
```

</div>
