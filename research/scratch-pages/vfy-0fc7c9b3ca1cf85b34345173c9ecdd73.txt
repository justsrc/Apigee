<div id="google.cloud.apigee.v1.ApiProxyService.UpdateApiProxyRevision" class="section">

</div>

<div id="description" class="section">

Updates an existing API proxy revision by uploading the API proxy configuration bundle as a zip file from your local machine.

You can update only API proxy revisions that have never been deployed. After deployment, an API proxy revision becomes immutable, even if it is undeployed.

Set the `Content-Type` header to either `multipart/form-data` or `application/octet-stream`.

</div>

<div id="body" class="section">

<div id="body.HTTP_TEMPLATE" class="section">

### HTTP request

`POST https://apigee.googleapis.com/v1/{name=organizations/*/apis/*/revisions/*}`

The URL uses [gRPC Transcoding](https://google.aip.dev/127) syntax.

</div>

<div id="body.PATH_PARAMETERS" class="section">

### Path parameters

| Parameters |  |
| --- | --- |
| name | string Required. API proxy revision to update in the following format: organizations/{org}/apis/{api}/revisions/{rev} If the API Proxy resource has the space attribute set, IAM permissions are checked against the Space resource path. To learn more, read the Apigee Spaces Overview . Authorization requires the following IAM permission on the specified resource name : apigee.proxyrevisions.update |

</div>

### Query parameters
