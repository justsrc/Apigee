<div id="NAME" class="section">

NAME

<span class="normalfont"> gcloud apigee developers - manage Apigee developers </span>

</div>

<div id="SYNOPSIS" class="section">

SYNOPSIS

<span class="normalfont"> `gcloud apigee developers` [`COMMAND`](#COMMAND) \[[`GCLOUD_WIDE_FLAG`](#GCLOUD-WIDE-FLAGS)` …`\] </span>

</div>

<div id="DESCRIPTION" class="section">

DESCRIPTION

Manage Apigee developers.

`gcloud apigee developers` manages developers that want to use APIs exposed via Apigee in their applications.

</div>

<div id="EXAMPLES" class="section">

EXAMPLES

To list the email addresses of all the developers in the active Cloud Platform project, run:

<div>

</div>

``` devsite-click-to-copy
gcloud apigee developers list
```

To get that list as a JSON array and only include developers with `example.com` addresses, run:

<div>

</div>

``` devsite-click-to-copy
gcloud apigee developers list --format=json --filter="email:(@example.com)"
```

To get details about a specific developer in the active Cloud Platform project, run:

<div>

</div>

``` devsite-click-to-copy
gcloud apigee developers describe DEVELOPER_EMAIL
```

</div>

<div id="GCLOUD-WIDE-FLAGS" class="section">

GCLOUD WIDE FLAGS

These flags are available to all commands: [`--help`](/sdk/gcloud/reference#--help).

Run `$ `[`gcloud help`](/sdk/gcloud/reference) for details.

</div>

<div id="COMMAND" class="section">

COMMANDS

`COMMAND` is one of the following:

<span class="normalfont">[`describe`](/sdk/gcloud/reference/apigee/developers/describe)</span>  
Describe an Apigee developer.

<span class="normalfont">[`list`](/sdk/gcloud/reference/apigee/developers/list)</span>  
List Apigee developers by email address.

</div>
