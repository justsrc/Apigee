<div id="google.cloud.apigee.v1.DeveloperApps.CreateDeveloperApp" class="section">

</div>

<div id="description" class="section">

Creates an app associated with a developer. This API associates the developer app with the specified API product and auto-generates an API key for the app to use in calls to API proxies inside that API product.

The `name` is the unique ID of the app that you can use in API calls. The `DisplayName` (set as an attribute) appears in the UI. If you don't set the `DisplayName` attribute, the `name` appears in the UI.

</div>

<div id="body" class="section">

<div id="body.HTTP_TEMPLATE" class="section">

### HTTP request

`POST https://apigee.googleapis.com/v1/{parent=organizations/*/developers/*}/apps`

The URL uses [gRPC Transcoding](https://google.aip.dev/127) syntax.

</div>

<div id="body.PATH_PARAMETERS" class="section">

### Path parameters

| Parameters |  |
| --- | --- |
| parent | string Required. Name of the developer. Use the following structure in your request: organizations/{org}/developers/{developerEmail} Authorization requires the following IAM permission on the specified resource parent : apigee.developerapps.create |

</div>

<div id="body.request_body" class="section">

### Request body

The request body contains an instance of [`DeveloperApp`](/apigee/docs/reference/apis/apigee/rest/v1/organizations.developers.apps#DeveloperApp).

</div>

<div id="body.response_body" class="section">

### Response body

If successful, the response body contains a newly created instance of [`DeveloperApp`](/apigee/docs/reference/apis/apigee/rest/v1/organizations.developers.apps#DeveloperApp).

</div>

<div id="body.aspect" class="section">

### Authorization scopes

Requires the following OAuth scope:

- `https://www.googleapis.com/auth/cloud-platform`

</div>
