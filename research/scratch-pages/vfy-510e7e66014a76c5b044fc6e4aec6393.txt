<div id="NAME" class="section">

NAME

<span class="normalfont"> gcloud alpha apigee - manage Apigee resources </span>

</div>

<div id="SYNOPSIS" class="section">

SYNOPSIS

<span class="normalfont"> `gcloud alpha apigee` [`GROUP`](#GROUP) \[[`GCLOUD_WIDE_FLAG`](#GCLOUD-WIDE-FLAGS)` …`\] </span>

</div>

<div id="DESCRIPTION" class="section">

DESCRIPTION

`(ALPHA)` Manage Apigee resources.

</div>

<div id="EXAMPLES" class="section">

EXAMPLES

To list API proxies in the active Cloud Platform project, run:

<div>

</div>

``` devsite-click-to-copy
gcloud alpha apigee apis list
```

To deploy an API proxy named `hello-world` to the `test` environment, run:

<div>

</div>

``` devsite-click-to-copy
gcloud alpha apigee apis deploy --environment=test --api=hello-world
```

To get the status of that deployment, run:

<div>

</div>

``` devsite-click-to-copy
gcloud alpha apigee deployments describe --environment=test --api=hello-world
```

To undeploy that API proxy, run:

<div>

</div>

``` devsite-click-to-copy
gcloud alpha apigee apis undeploy --environment=test --api=hello-world
```

</div>

<div id="GCLOUD-WIDE-FLAGS" class="section">

GCLOUD WIDE FLAGS

These flags are available to all commands: [`--help`](/sdk/gcloud/reference#--help).

Run `$ `[`gcloud help`](/sdk/gcloud/reference) for details.

</div>

<div id="GROUP" class="section">

GROUPS

`GROUP` is one of the following:

<span class="normalfont">[`apis`](/sdk/gcloud/reference/alpha/apigee/apis)</span>  
`(ALPHA)` Manage Apigee API proxies.

<span class="normalfont">[`applications`](/sdk/gcloud/reference/alpha/apigee/applications)</span>  
`(ALPHA)` Manage third-party applications which call Apigee API proxies.

<span class="normalfont">[`archives`](/sdk/gcloud/reference/alpha/apigee/archives)</span>  
`(ALPHA)` Manage Apigee archive deployments.

<span class="normalfont">[`deployments`](/sdk/gcloud/reference/alpha/apigee/deployments)</span>  
`(ALPHA)` Manage deployments of Apigee API proxies in runtime environments.

<span class="normalfont">[`developers`](/sdk/gcloud/reference/alpha/apigee/developers)</span>  
`(ALPHA)` Manage Apigee developers.

<span class="normalfont">[`environments`](/sdk/gcloud/reference/alpha/apigee/environments)</span>  
`(ALPHA)` Manage Apigee environments.

<span class="normalfont">[`operations`](/sdk/gcloud/reference/alpha/apigee/operations)</span>  
`(ALPHA)` Manage Apigee long running operations.

<span class="normalfont">[`organizations`](/sdk/gcloud/reference/alpha/apigee/organizations)</span>  
`(ALPHA)` Manage Apigee organizations.

<span class="normalfont">[`products`](/sdk/gcloud/reference/alpha/apigee/products)</span>  
`(ALPHA)` Manage Apigee API products.

</div>

<div id="NOTES" class="section">

NOTES

This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available:

<div>

</div>

``` devsite-click-to-copy
gcloud apigee
```

<div>

</div>

``` devsite-click-to-copy
gcloud beta apigee
```

</div>
